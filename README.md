
# File Protection Utility

## Project Description
A Python-based cybersecurity application that protects files through password-based encryption and allows authorized users to restore them through decryption.

## Features
- Password-based file encryption.
- Secure file decryption.
- Incorrect password detection.
- Corrupted file detection.
- Supports different file formats.
- Preserves original files.
- Uses authenticated encryption.

## Technologies Used
- Python 3
- Cryptography Library
- Fernet Encryption
- PBKDF2HMAC
- SHA-256
- Python IDLE

## Installation
Install the required library:

pip install cryptography

## How to Run
1. Open the Python file in IDLE.
2. Press F5.
3. Select Encrypt or Decrypt.
4. Enter the file path.
5. Enter the required password.
6. Check the generated output file.

## Objective
To understand file security, encryption, decryption, password-based key derivation and data protection.

## Disclaimer
This project is developed for educational purposes. Keep secure backups of original files and encryption passwords.
